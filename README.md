## 📌 Overview

A responsive digital calculator featuring tactile button feedback, arithmetic precision, keyboard input support, and an ergonomic keypad layout.

---

## ✨ Key Features

- **Standard Mathematical Operators:** Addition, Subtraction, Multiplication, Division, and Percentage operations.
- **Decimal & Chained Calculations:** Handles complex sequential calculations with continuous operator chaining.
- **Tactile Button Feedback:** Active depression animations simulating real physical calculator keys.
- **Clear & Backspace Functions:** Instant AC (All Clear) and single-character backspace controls.

---

## 💻 Tech Stack & Architecture

- **Technologies:** Semantic HTML5, CSS3 Grid Layouts, JavaScript Arithmetic Evaluator
